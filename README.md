# Чистовик — текст без опечаток

Программа для macOS: исправляет раскладку, опечатки, пропущенные пробелы, «ё», дефисы и запятые прямо при наборе.

**Скачать последнюю версию:** [Chistovik.dmg](https://github.com/akuzin8/chistovik-releases/raw/main/Chistovik.dmg)

Откройте файл, перетащите «Чистовик» в папку «Программы» и запустите. Дальше программа сама сообщает о новых версиях.

Страница программы: [akuzin.ru/programs/chistovik](https://akuzin.ru/programs/chistovik)
